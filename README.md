# search-xkcd
Проект, целью которого является создание поисковой системы для сайта xkcd.com

Система создаётся поэтапно и процесс состоит из 10 отдельных заданий

В каждом задании присутствуют тесты, которые запускаются через команды в make-файле

# Основные команды в каждом из заданий
+ **make up** - сборка проекта и запуск
+ **make down** - остановка и удаление контейнеров
+ **make clean** - остановка с очисткой томов(volumes)
+ **make run-tests** - запуск тестов (без сборки проекта)
+ **make test** - запуск тестов (с предварительной сборкой)
+ **make proto** - генерация кода по заданным proto-файлам
+ **make lint** - запуск линтера для проверки написания кода
